# DEV JAM 2023

## Name
Pat-ines

## Description
Patines es un juego plataformas en tercera persona donde nos pondremos en la piel de un pato patinador atrapado en un místico museo donde deberá de adentrarse en los cuadros para revivir situaciones de su vida y así superar una pérdida.
